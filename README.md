# 🛍️  Projet E-Commerce

## 📌 Description

Ce projet est une application e-commerce développée en groupe dans le cadre d’un travail collaboratif.
L’objectif est de permettre à 
> un utilisateur de :

* Consulter les produits disponibles

* Ajouter des articles au panier

* Passer une commande

* Gérer son profil

> L’administrateur peut gérer le catalogue, les utilisateurs et les commandes.

##  ⚙️  Fonctionnalités principales

🔎 * Parcourir et rechercher des produits

🛒 * Ajouter au panier et valider la commande

👤 * Gestion du compte utilisateur (connexion / inscription)

📦 * Suivi des commandes

🛠️ * Interface d’administration (gestion des produits, stocks, commandes)


 ## 🛠️  Technologies utilisées

* Frontend : React.js

* Backend : Node.js / Express

* Base de données : MySQL 

* Autres outils : GitHub


  🚀 ## Installation et utilisation

 ### 1.  Cloner le projet :
   > [!NOTE]
   > git clone [https://github.com/votre-utilisateur/nom-du-repo.git](https://github.com/237ndjassab/ecommerce_projet.git)
   > cd nom-du-repo
 ### 2. Installer les dépendances :
   > [!NOTE]
   > npm install
 ### 3. Lancer le serveur :
   > [!NOTE]
   > npm run dev
 ###  4. Accéder à l’application :
   > [!NOTE]
   > Ouvrir http://localhost:3000 dans le navigateur.
